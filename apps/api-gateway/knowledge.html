Sổ tay API Gateway
Tổng quan Kiến thức Luyện câu hỏi Từ điển Slide
Contract-first · HTTP → TCP RPC · NestJS + Fastify

Một file OpenAPI, một gateway dùng lại cho mọi project.

operationId trong spec chính là @MessagePattern của service. Gateway tra route, hỏi service discovery xem ai xử lý pattern đó, rồi gửi message qua TCP.

Kiến trúc

Gateway lo traffic bắc-nam (client vào hệ thống). Event giữa các service đi qua RabbitMQ, gateway không chạm tới.

Control plane và data plane

Việc nặng làm một lần lúc khởi động. Mỗi request chỉ tra dữ liệu đã có trong bộ nhớ.

Lúc khởi động · bootstrap.ts

Control plane: chuẩn bị luật

chạy hiếm · ưu tiên đúng · lỗi thì exit 1, không mở cổng
  1. Đọc env, chọn project, chặn path traversal config.ts
  2. Đọc + validate OpenAPI, ép luật operationId spec-loader.ts
  3. Dựng segment trie route-table.ts
  4. Nạp bảng pattern → instance static-discovery.ts
  5. Cảnh báo pattern chưa ai đăng ký
Gom mọi lỗi rồi báo một lần, để người viết spec sửa một lượt.
Mỗi request · gateway-handler.ts

Data plane: áp luật cho request

chạy liên tục · ưu tiên nhanh · chỉ đọc bộ nhớ
  1. Lấy hoặc sinh x-request-id
  2. Match route trong trie, O(số segment)
  3. Dựng payload theo allowlist
  4. Hỏi discovery: ai xử lý pattern này?
  5. Gửi TCP, dịch kết quả và lỗi sang HTTP
Control plane chết thì data plane vẫn chạy bằng cấu hình đã nạp.

Một request đi qua gateway

Chọn một tình huống để xem request dừng ở bước nào và gateway trả về gì. Bấm vào từng bước để đọc chi tiết.
